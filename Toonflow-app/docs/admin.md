# 账号与后台管理

本文说明创梦本地部署的账号体系、后台管理模块与数据位置。适用于 `apps/server` + `apps/web` 的自托管形态。

## 首次启动

1. 启动服务后打开 `http://localhost:5173`。
2. 系统检测到尚无账号时，会进入 `/setup` 初始化页。
3. 创建第一个管理员账号（用户名 3-32 位字母、数字或 `_ . -`；密码至少 8 位且同时包含字母和数字）。
4. 创建成功后自动登录并进入创作首页。

初始化完成后，所有页面都要求登录。未登录访问任何业务页面会跳转到 `/login`。

## 角色与权限

| 能力 | 管理员 admin | 成员 member | 只读 viewer |
| --- | --- | --- | --- |
| 创作、画布、生成 | 是 | 是 | 可浏览，不可保存配置 |
| 读取模型与供应商配置 | 是（含密钥） | 是（含密钥） | 密钥字段脱敏为空 |
| 修改系统设置 / 供应商 | 是 | 是 | 否（403） |
| 进入 `/admin` 后台 | 是 | 否（跳回首页） | 否 |
| 管理账号、重置密码 | 是 | 否 | 否 |

约束：系统始终保留至少一个启用状态的管理员；管理员不能停用、降级或删除自己。

## 后台模块

访问 `/admin`（仅管理员）：

- **仪表盘**：成员、项目、今日生成、存储占用四项指标，近 7 天生成趋势，最近操作与活跃项目。
- **成员管理**：搜索、按角色筛选、新建账号、编辑资料与角色、启用/停用、重置密码、删除账号。
- **项目管理**：扫描 `data/workspaces` 下的项目，显示画布数、素材数、占用与修改时间。删除会先移入 `data/.trash/<项目名>-<时间戳>`，不是立即销毁。
- **用量统计**：近 7/30/90 天的生成请求次数、请求成功率、按媒体类型分布、模型与成员用量。
- **操作日志**：登录成功/失败、退出、账号增删改、密码重置、项目删除、系统设置变更，含操作者、对象、IP 与时间。
- **系统设置**：站点名称、登录有效期（1-30 天）、默认新账号角色、开放自助注册、未开通提示；运行环境与供应商配置状态。

## 数据与备份

| 文件 | 内容 |
| --- | --- |
| `data/system.db` | 账号、会话、操作日志、用量记录、系统设置（SQLite，WAL 模式） |
| `data/settings.json` | 原有应用配置（模型、供应商密钥、界面偏好） |
| `data/workspaces/` | 画布项目与素材 |
| `data/.trash/` | 后台删除项目后的回收站 |

`data/system.db` 含密码哈希（argon2id）与会话令牌哈希，不会随 Git 提交，但**需要纳入备份**。迁移机器时连同 `data/` 一起复制即可保留账号与项目。

会话令牌只以 SHA-256 哈希落库，Cookie 为 `HttpOnly + SameSite=Lax`，有效期由后台「登录有效期」控制；勾选「保持登录」固定为 30 天。

## 接入方式

- 登录网关挂载在 `apps/server/src/app.ts` 的 `/api` 路由之前，公开路径仅 `/api/auth/*`、`/api/desktop/*`、`/api/mobileLink/*`、`/api/channel/*`。
- 已配对的移动设备由 mobileLink 网关校验设备令牌后在 `res.locals.toonflowDeviceId` 打标，登录网关放行成员级请求；后台接口仍要求管理员 Cookie。
- 新增后台接口请放在 `apps/server/src/routes/admin/**`，执行 `bun run routes` 重新生成注册表，不要手改 `router.ts`。

## 忘记管理员密码

项目数据不会受影响，二选一：

1. 直接重置密码（在 `Toonflow-app` 目录执行，替换用户名与新密码）：

```bash
bun -e 'import { Database } from "bun:sqlite"; const db = new Database("data/system.db"); const hash = await Bun.password.hash("NewPass123", { algorithm: "argon2id" }); db.run("UPDATE users SET password_hash = ?, updated_at = ? WHERE username = ?", [hash, Date.now(), "admin"]); console.log("ok");'
```

2. 删除 `data/system.db` 后重启服务，重新走 `/setup` 初始化。此操作会清空账号、日志与用量，但不会删除画布项目。

## 已知边界

- 用量统计为**请求级**：记录生成接口的提交次数、HTTP 结果与耗时；异步任务的最终成败以画布内节点状态为准。
- 后台供应商页只展示“已配置/未配置”，不展示密钥明文，也不提供密钥编辑；密钥仍在创作端的设置面板维护。
- 操作日志保留在库内，暂未做自动清理；数据量较大时可按 `created_at` 归档。
