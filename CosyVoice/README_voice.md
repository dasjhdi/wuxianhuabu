# 本地音色克隆（CosyVoice2）使用说明

## 1. 启动服务

```bat
cd /d D:\wuxianhuabu\CosyVoice
.venv\Scripts\python.exe server_local.py
```

首次启动加载模型约 30–60 秒，常驻显存约 3 GB。

## 2. 打开音色库页面

浏览器访问 **http://127.0.0.1:8100/**

页面提供：

- 拖入音频 + 填逐字文本 → 一键保存
- 任意格式自动转 16 kHz 单声道（wav / mp3 / m4a / flac / ogg）
- 保存后自动合成一句样音，直接听克隆效果
- 已注册音色列表：试听参考音频、试听克隆效果、删除
- 同名 ID 保存时二次确认，避免误覆盖

## 3. 在画布里使用

**无需手填音色 ID**。上传成功后，音色会自动同步为画布里的可选模型：

1. 添加「音频生成」节点
2. 供应商选「**本地音色克隆**」
3. 模型下拉中直接选角色名（如「凌清砚」）
4. 输入台词 → 生成

删除音色后，下拉选项同步消失。

## 4. 素材要求

| 项 | 要求 |
|---|---|
| 时长 | 3–30 秒，建议 10–20 秒 |
| 格式 | wav / mp3 / m4a / flac / ogg（自动转码） |
| 内容 | 单人说话，无背景音乐、无混响回声、无爆音 |
| 文本 | 与音频**一字不差**，含标点；不要加「旁白：」等标签 |

## 5. 文件结构（一般无需手动操作）

```
CosyVoice/
    voices/<音色ID>/
        ref.wav      # 已标准化为 16 kHz 单声道 PCM16
        prompt.txt   # 逐字文本
        meta.json    # 显示名、备注、时长
```

供应商文件 `Toonflow-app/data/providers/localVoice.ts` 由服务在每次上传/删除后自动重写，**不要手动编辑**。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开 | 音色服务未启动，见第 1 步 |
| 提示「参考音频需为 3–30 秒」 | 剪辑一段 10 秒左右的干净片段 |
| 音色不像 | 参考音频换更干净的单人片段；文本必须逐字一致 |
| 画布下拉没有新音色 | 刷新页面；模型列表在每次请求时重新读取 |
| 显存不足 | 模型占约 3 GB，先关闭其他占用 GPU 的程序 |
